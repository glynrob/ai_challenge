AI Challenge 2.0 is a 4-week hands-on learning sprint where you work through real AI use cases and build practical skills step by step. It includes:

- Weekly tasks
- Real project scenarios
- Friendly competition
- A leaderboard

All designed to help you confidently use AI in everyday work.
